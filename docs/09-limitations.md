# 09 — Limitations

1. A two-node Docker lab is not a municipal production topology.
2. The included DCS is single-node and therefore not itself highly available.
3. Docker networking does not reproduce every WAN/cloud characteristic.
4. Container kill is a node-process failure, not a complete datacenter disaster.
5. The example cost model is not a bill or vendor quotation.
6. Results from PostgreSQL cannot be generalized to SQL Server or Oracle without rerunning equivalent workload protocols.
7. Security/compliance scoring requires organization-specific legal, risk and data-classification input.
8. A public GitHub repository must never include production credentials, internal hostnames, security logs or personal data.
